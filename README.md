Universal MGP calculating device for my old vehicle.

There are multiple versions that are possible:
- scroll to add the exact distance (the change)
- scroll to add distance on a stored vehicle milage (move it to the new milage on the dashboard)
- GPS tracking to add the distance (auto updating)
- time (if there is a lack of a clock, this can default to a clock)
, these are just some ideas for potential project developments (maybe visable in different branches). This project is mostly
a play around for hardware projects and other small tech solutions to make my life easier.
